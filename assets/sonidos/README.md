# Efectos de audio

Coloca aquí los efectos libres de derechos usados por la aplicación:

- `clic.mp3`: confirmación corta de interfaz.
- `construir.mp3`: construcción completada.
- `mejorar.mp3`: mejora de edificio completada.
- `reclamar.mp3`: recompensa de meta.
- `evento.mp3`: aparición o resolución de un evento.
- `aldeano.mp3`: llegada de un aldeano.

Fuentes recomendadas:

- Kenney: https://kenney.nl/assets?q=audio
- Pixabay Audio: https://pixabay.com/sound-effects/
- Freesound: https://freesound.org/

Revisa siempre la licencia concreta de cada descarga. Prefiere archivos CC0 y respeta atribución o ShareAlike cuando corresponda.

Se recomienda MP3 mono, 44.1 kHz y menos de 3 segundos por efecto.
